# Find It! 3D (FindRoom3D) — model & texture credits

All assets here are **CC0 1.0** (public domain) unless noted. Every model was re-packed for the web with
glTF-Transform (dedup / weld / light simplify, textures downscaled to 256–1024 px).
Some Poly Haven sets were split so that one file holds one object (noted "part of …").
